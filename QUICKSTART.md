# Quick Start Guide - MAA PADMAWATI SAREES

## 🚀 Get Started in 5 Minutes

### Step 1: First Time Setup (2 minutes)

1. **Open Dashboard**
   - Click the MAA PADMAWATI SAREES banner
   - You'll see the main dashboard with quick access buttons

2. **Create a Customer**
   - Go to **Settings** tab
   - Add customer/party details
   - Note down the Party ID (e.g., 1)

3. **Create Products**
   - Click **Products** tab (🏷️ icon)
   - Click **"Generate New Item ID"**
   - System creates a unique ID (e.g., PROD-20250121-A7F2K)
   - Enter product name (e.g., "Silk Saree Red")
   - Enter sale price
   - Click **"Save Item"**
   - **Print the QR code label** and attach to the dress

### Step 2: Make Your First Sale (1 minute)

1. **Open Quick Sale**
   - Click **Quick Sale** tab (⚡ icon)

2. **Enter Invoice Details**
   ```
   Bill No.     : 1001
   Date         : 21-Jan-2025  (today's date)
   Party ID     : 1
   Party Name   : Customer Name
   ```

3. **Add Product**
   - **Scan the QR code** you printed (or type the Item ID)
   - Click "Search"
   - Product details appear:
     - Product name
     - Sale price
     - Purchase price (if set)
   
4. **Confirm and Add**
   - Quantity auto-fills as 1
   - Change if buying multiple
   - Click **"Add Item to Invoice"**

5. **Repeat or Save**
   - Add more items (repeat Step 3-4)
   - Or click **"Save & Print Invoice"** to finish

6. **Print**
   - Professional bill prints with:
     - Product details
     - Prices
     - GST calculation
     - Total amount

## ⚠️ Common Mistakes to Avoid

### ❌ Mistake 1: Forgetting to Print Labels
- **Do this**: Print QR codes for ALL products first
- **Then**: Label and display items
- **Then**: Use Quick Sale for fast checkout

### ❌ Mistake 2: Typing Item ID Instead of Scanning
- **Don't do**: Manual typing (slow and errors)
- **Do this**: Use barcode scanner
- **Benefit**: 100% accuracy, 10x faster

### ❌ Mistake 3: Not Setting Sale Price When Creating Item
- **Don't**: Leave sale price blank
- **Do this**: Always enter sale price
- **Why**: Required for quick sale system

### ❌ Mistake 4: Creating Item Multiple Times
- **Don't**: Create same product 10 times
- **Do this**: Create once, sell multiple times
- **Example**: Create "Silk Saree Red" ONCE, then scan it for each customer

### ❌ Mistake 5: Wrong Party ID in Invoice
- **Check**: Party ID matches customer in system
- **Do**: Verify before saving
- **Impact**: Wrong sales reports if missed

## 🔧 Troubleshooting

### "Product not found" Error
- **Check**: Item ID is correct (copy from label)
- **Check**: QR code is readable
- **Solution**: Try scanning again or type carefully

### "Cannot save invoice" Error
- **Check**: Bill No. is filled
- **Check**: Party ID is valid
- **Check**: At least one item added
- **Solution**: Fill all required fields

### QR Code not printing clearly
- **Solution**: In Products tab, click QR code image
- **Print**: From your print dialog
- **Adjust**: Printer quality settings if needed

### Sale price showing as 0
- **Check**: You entered sale price when creating item
- **Solution**: Go to Products, create new item with price

## 📞 Need Help?

### Check These First
1. **Product Not Found?**
   - Verify product exists in Products tab
   - Check Item ID spelling exactly
   - Try scanning again

2. **Invoice Won't Save?**
   - Fill all required fields (marked with *)
   - Ensure at least 1 item added
   - Check Party ID is valid number

3. **Print Not Working?**
   - Click "Save & Print Invoice" button
   - Or use browser Print (Ctrl+P)
   - Check printer is connected

4. **Prices Wrong?**
   - Each item has individual price
   - Check price when creating item
   - Scan item to confirm price
